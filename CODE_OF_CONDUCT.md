# Código de conducta

Este proyecto adopta el **[Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/)**.

En resumen: trato respetuoso, crítica al código y no a las personas, cero acoso y bienvenida a gente de cualquier nivel. Las propuestas se discuten con argumentos técnicos.

Para informar de un comportamiento inaceptable, escribe en privado a los mantenedores ([@FernandoBaqueroo](https://github.com/FernandoBaqueroo), [@Necro-Coder](https://github.com/Necro-Coder)) a través de GitHub. Toda denuncia se revisa con confidencialidad.
