Qué hace

Fuente única

Reglas y skills en ~/.agents. Claude Code lo importa, Antigravity, Codex y Copilot lo enlazan y Cursor lo lee de serie. Editas una vez y lo ven todos.

Calidad CSR

Puerta de validez en 8 fases, seguridad OWASP/ASVS/CWE, tests y tabla de gates. Las respuestas son cortas: el agente gasta tokens en pensar, no en hablar.

Multiagente automático

El agente detecta cuándo una tarea se puede repartir y lanza un agente por parte, cada uno en su worktree. Con spec-kit, /speckit.implement lo hace solo. Tú confirmas el plan, el merge final y la limpieza.

Roles y modelos

Cada parte recibe un rol y un nivel de modelo: alto para arquitectura, seguridad y código sensible; medio para implementar; bajo para lo mecánico. Qué modelo es cada nivel lo dices tú una vez en ~/.agents/models.md, y los modelos nuevos entran sin reinstalar.

Worktrees sanos

Cada run parte de origin actualizado, cada worktree nace con sus dependencias y su .env de desarrollo, y al terminar ves lo que ha quedado y se borra con tu permiso.

Instalar

Requisitos: macOS, Linux, WSL o Git Bash. Para npx y omk, Node 18 o superior. El instalador hace backup de todo lo que toca y se deshace con omk restore.

Comandos

COMANDOQUÉ HACE
omk installInstala o migra la fuente única para los agentes detectados. Admite --dry-run y --agents claude,codex
omk init [ruta]Prepara un proyecto: AGENTS.md, CLAUDE.md, STACK.md, ORCHESTRATION.md
omk verifyComprueba enlaces, imports y que no queden copias divergentes
omk adopt <skill>Comparte una skill externa (por ejemplo, impeccable) con todos los agentes
omk backups · omk restore <fecha>Lista las copias de seguridad y deshace una instalación
omk updateActualiza a la última versión y reinstala
omk where · omk versionRutas y versión

Dentro de cada agente solo necesitas dos frases: «inicializa el proyecto» la primera vez y, con spec-kit, /speckit.implement como siempre. El reparto lo propone el agente. Todo el flujo, en la guía visual.
